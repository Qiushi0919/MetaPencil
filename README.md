# MetaPencil

MetaPencil 是一个以 MATLAB 为主的研究项目：用时变 1/2-bit 可编程反射超表面的快时间与慢时间编码，把真实飞机的复原始回波搬移为指定 SAR 距离—方位假目标，并研究 2-bit 量化高阶谐波副像的抑制。

当前仓库是 2026-08-24 交接快照的私有 Git 化版本。它包含可追溯源代码、配置、小型样例、精选基线结果、PPT/PDF 研究材料和烟雾测试；没有宣称已完成全波、共形硬件或真实雷达实验。

## 当前最主要成果

- 30/70 1-bit、平衡 2-bit、2-bit + 四时延相消三类复回波/RD 基线。
- 使用 `[0, 1/10, 5/6, 14/15]T` 时延集合保留 `+1` 阶，并在理想系数模型中使 `-3/+5` 阶接近零。
- 单机 `1→1/2/3/4/5/9/16`、双机共享/独立码本、四机 16 目标和若干离散形状结果。
- 结果、控制表、公式—代码映射和原始交接清单均可追溯。

## 快速开始

先运行不依赖完整 SAR 批处理的烟雾测试：

```bash
python3 handoff_tools/run_smoke_test.py
```

或在 MATLAB 中：

```matlab
run('handoff_tools/run_smoke_test.m')
```

完整研究入口：

```matlab
cd('source/2 暑假_两个月仿真任务/Week 5 0815之前/SAR假目标自由度与物理阵列')
run_full_array_freedom_study
```

完整批量默认使用 700 个散射点、`Na=288`、`Nr=2048`，预计为数十分钟级；高精度历史版本可能需要明显更多内存。

## 当前模型边界（必须先知道）

当前统一入口是理想二维点散射体 + 复原始回波/RD 模型，但还不是位置感知的有限超表面口径模型：

- 外层 `tile_map` 当前只统计各通道出现次数并形成面积权重；同样计数、不同空间排布会得到相同响应。
- 每个目标通道以面积权重乘整架飞机的复回波；没有把飞机散射点按真实宏格位置划分给各通道。
- 四态超表面假定单极化、无损、等幅且相差恰好 90°；未纳入互耦、斜入射色散、状态误差、噪声和真实控制时序。

这两项空间模型缺口是当前 P0 工作，不影响现有理想系数和历史基线的可追溯性，但限制了物理实现结论。
