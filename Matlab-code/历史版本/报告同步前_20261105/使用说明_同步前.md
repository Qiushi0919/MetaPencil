# 超表面 MATLAB 仿真代码

本项目用于研究可编程超表面的相位编码、时间调制、谐波分布和散射成像特性。平时只用 **当前代码**，其中保留综合研究和四散射模型示例两个版本。在 MATLAB 中打开对应的 `.m` 文件，点击“运行”即可。

| 程序 | 用途 |
|---|---|
| `four_aircraft.m` | 四个输入散射模型，比较四种输出排列的成像结果 |
| `main_study.m` | 综合研究：不同输入模型数量、调制通道数、阵列配置及形状输入，运行较久 |

`airplane_scatter_points.mat` 是这两个程序共用的数据，不要移走。保留 `phone_sketch_input/` 供完整研究程序读取自定义图片。

综合研究包括单输入模型的多通道响应、双输入模型的共享/独立码本对比、四输入模型的规则排列、阵列配置对比、自定义形状和谐波检查。四散射模型示例单独提供规则 4×4、五角星、风车和 ∞ 双环四种输出排列。

完整研究程序使用 `phone_sketch_input/phone_sketch.png` 作为自定义形状输入。现已附带一张带屋顶和门洞的小房子轮廓示例图，可以直接运行体验：

1. 程序读取这张图片，把它变成 7×7 的 0/1 表格。
2. 程序把识别出的表格保存为 `compiled_phone_mask_7x7.csv`，方便查看。
3. 程序使用同一份识别结果进行仿真，对应图保存为 `results_full_array_exact/arbitrary_phone_pair.png`。

输入是 PNG；CSV 是生成记录，程序不会读取你手工修改的 CSV。其余 `sample_*.csv` 是程序保存的内置形状示例。若找不到 PNG，旧程序会自动使用内置 Z 形。四散射模型示例使用自己的内置形状，不读取这个文件夹。

自定义图片建议使用白底黑线。现有程序按画面平均亮度判断背景，黑色大面积超过一半时可能识别反色；这张轮廓示例已按程序实际输出核对。

运行结果会自动保存在程序旁边各自的 `results_...` 文件夹。再次运行可能覆盖该程序上次的同名结果。

**历史版本** 保留以前按 Week 分类的程序、数据和结果，相互之间的相对路径保持不变。后续修改优先在“当前代码”中进行。

另外两个专项程序已移到 `历史版本/专项版本_20261021/`：`run_two_aircraft_independent_special_shapes.m`（双输入模型的形状示例）和 `run_clear_low_channel_shapes.m`（少通道图）。归档目录附有散射点数据副本，仍可独立运行。现有的综合研究和四散射模型示例结果保留在“当前代码”中。

文件名沿用现有名称，便于对应代码和已有结果；本说明不改变程序的实际计算流程。当前通道按权重作用于完整散射模型，尚未实现按实际单元位置划分散射点的有限口径模型。

交接文档、测试和校验清单已移到仓库 `项目管理/archive/matlab-support/`，日常运行不需要打开它们。当前代码仅改了散射点数据的读取路径，算法与默认参数沿用原版。
