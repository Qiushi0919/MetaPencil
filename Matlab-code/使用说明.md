# 超表面 MATLAB 报告复现

当前入口在 `Matlab-code/code/`。在 MATLAB 中打开 **`code/main_study.m`**，点击“运行”，即可从散射点重新生成回波、完成 RD 聚焦并输出报告中的 SAR 对比。程序不依赖 `项目管理/review_packets/`，也不使用旧结果缓存。

MATLAB R2025a 为本次验证环境。默认完整计算使用700个散射点、2426条回波，每条32768个复数样本；本机24 GB内存环境下，完整计算、保存和绘图约17.5分钟，输出约10.4 GiB，其他机器耗时会不同。输出放在 `code/results_report/日期_时间/`，每次运行新建目录，不覆盖历史结果。

## 当前文件

| 文件 | 用途 |

| `code/airplane_scatter_points.mat` | 默认计算使用的原始散射点数据 |

原来的多案例、四输入排列、可配置阵列和倾斜阵面程序，连同输入文件，完整备份在 **`历史版本/报告同步前_20261105/code/`**。运行旧功能时打开备份中的对应文件；它们保留旧参数。`code.zip`是既有旧快照，日常使用上述`code/`目录。

## 与最新报告一致的设置

| 参数 | 默认值及计算方式 |
|---|---|
| 工作频段 / 中心 / 带宽 | 9–10 GHz / 9.5 GHz / 1 GHz |
| 脉冲宽度 | 1 μs，调频斜率B/Tp＝10¹⁵ Hz/s |
| 平台高度 / 速度 | 500 m / 80 m/s |
| 中心入射角 | 60°，从竖直阵面法线量起 |
| 中心斜距 / 地距 | 1000 m / 866.0254 m |
| 快时间采样率 / 间隔 | 9.6 GSa/s / 0.104167 ns，复基带数值采样 |
| PRF / 脉冲间隔 | 3072 Hz / 0.325521 ms；相邻位置间隔0.0260417 m |
| 回波矩阵 | 2426×32768；快时间窗3.413333 μs |
| 名义距离分辨率 | 斜距c/(2B)＝0.15 m；地距c/(2B sin60°)＝0.173205 m |
| 方位设计值 / 名义孔径 | 0.25 m / λR0/(2ρa)＝63.157895 m |
| 阵面 | 水平，16×16个单元，间距15 mm |
| 编码 | 理想0/90/180/270°、等驻留；快慢延迟均为[0,1/10,5/6,14/15]T |
| 副本设计位置 | 地距、方位各±8 m，共四个 |

x为地距、y为方位、z竖直，雷达视线随慢时间改变。空间响应使用`mean(Gamma .* exp(+j*2*k*s·r))`，原始回波仍使用`exp(-j*4*pi*R/lambda)`。没有加固定位置或随轨迹变化的方向补偿。

## 函数调用

```matlab
% 默认完整报告案例
result = main_study_spatial;

% 只重新绘图，也可将参数换成某次输出目录的绝对路径
plot_report_results(result.output_dir)

% 只计算单点，仍用完整孔径和采样
point = main_study_spatial(struct('mode','point','make_plots',false));

% 独立采样加密对照
fine = main_study_spatial(struct('mode','point','Fs',19.2e9,'PRF',3072));
```

重新绘图只更新该目录下同名PNG/FIG和绘图清单，不重算或覆盖复数MAT数据。可用`output_dir`指定新的或空的输出目录。改变Fs或PRF后会重算采样点数，不再是默认报告配置。新版默认范围为报告1→4案例；旧`case_ids`、`tile_map`接口保留在备份程序中。

## 模型边界

这是理想载频有限阵因子乘完整目标复回波，再用报告相同的RD算法聚焦。水平空间模型包含单元坐标和移动雷达的阵内双程相位，但没有实现散射点对物理分区的归属，也未接入实际宽带斜入射四态单元、互耦、噪声或实测数据。

显示−80 dB弱结构不表示实际可检测，既有检查没有证明全部−80 dB旁瓣收敛。0.25 m是方位设计输入，Fs和PRF是数值设置。9–10 GHz为发射频段，调制主阶可能越出该频段，真实器件和接收频带仍需另行验证。
