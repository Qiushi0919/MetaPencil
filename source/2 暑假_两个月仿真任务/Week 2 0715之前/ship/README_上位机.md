# 四超表面 SAR 仿真控制台

## 启动

在 MATLAB 中把当前文件夹切换到 `ship`，运行：

```matlab
ship_control_app
```

原来的 `SHIP.m`、`ship_trans.m` 和已有散射点文件均保留，未被覆盖。

## 界面能做什么

- 分别修改 4 块超表面的方位向、距离向相对位置；
- 修改每块超表面的慢时相位序列、快时相位码及重复次数；
- 实时预览四组三联点、超表面中心和覆盖范围；
- 使用十字对称、横向排列等快捷布局；
- 保存或载入 MAT/JSON 配置；
- 生成新的 `four_group_scatter_points.mat/.txt`；
- 把当前参数生成一份可编辑、可直接运行的 MATLAB 脚本；
- 运行 RD 成像、停止长任务并导出结果；
- 运行前估算目标点数、Na/Nr 和峰值内存，避免误操作卡死 MATLAB。

## 坐标约定

- 表格“方位”对应 SAR 图纵轴；
- 表格“距离”对应 SAR 图横轴；
- 表格坐标、三点间距和覆盖半宽是缩放前的相对值；
- 进入仿真时，它们会统一乘以“场景缩放”。

## 推荐使用顺序

1. 在表格中设置 4 块超表面的位置；
2. 点击“刷新预览”，检查三联点和覆盖框是否重叠；
3. 先使用 `manual` 模式和默认小采样数试跑；
4. 确认参数正确后逐步增大 Na、Nr 和目标采样密度；
5. 需要留档时保存配置或生成 MATLAB 代码。

`auto` 模式会按照原 `SHIP.m` 的雷达公式推导采样数；当前默认雷达参数得到 `Na=256、Nr=4096`。以后增大场景范围、带宽等参数时采样规模可能快速增长，因此运行前仍应查看界面的内存估算。

生成的 MATLAB 脚本会自动加入本控制台所在目录，以便找到仿真辅助函数。若把脚本复制到另一台电脑，还需要同时复制本目录下以 `ship_` 开头的函数文件。
