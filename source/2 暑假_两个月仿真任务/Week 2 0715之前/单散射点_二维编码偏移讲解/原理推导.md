# 为什么一个散射点会在二维图像中形成多个偏移点

## 1. 快时间编码控制距离向间距

未编码的距离向线性调频回波可写成：

```text
s(t) = exp(j*pi*Kr*(t-tau0)^2)
```

如果快时间周期相位码包含一个频率分量 `f_rg`，相当于回波又乘上：

```text
exp(j*2*pi*f_rg*t)
```

完成平方后，它等价于把线性调频脉冲的压缩峰移动 `f_rg/Kr` 秒。因此对应的斜距偏移绝对值为：

```text
Delta_R = c*f_rg/(2*|Kr|)
```

本例让 `[0,0,pi]` 在一个脉冲 `Tp` 内重复 `fast_cycles` 次，所以码的基频为：

```text
f_rg = fast_cycles/Tp
```

最终相邻频率谐波对应的距离间距为：

```text
Delta_R = c*fast_cycles/(2*|Kr|*Tp)
        = c*fast_cycles/(2*Br)
```

因此，在其他参数不变时，`fast_cycles` 加倍，距离向复制间距也加倍。

## 2. 慢时间编码控制方位向间距

点目标的慢时间方位回波近似为：

```text
s(eta) = exp(j*pi*Ka*(eta-eta0)^2)
```

慢时间周期码的一个频率分量 `f_az` 会使方位多普勒发生平移。方位匹配滤波后，对应的空间偏移绝对值为：

```text
Delta_x = v*f_az/|Ka|
```

若一个慢时间码周期占 `L` 个脉冲，脉冲重复频率为 `PRF`，则：

```text
f_az = PRF/L
Delta_x = v*PRF/(|Ka|*L)
```

因此 `L` 越小，码变化越快，方位向复制间距越大。

## 3. 为什么得到的不是只有一个移动点

单一复指数相位斜坡只包含一个频率，会主要产生一个移动后的点。但 `[0,0,pi]` 或 0/π 方波是周期性的 1-bit 码，它的傅里叶级数包含直流分量、正负基频和多个高次谐波。

所以：

- 每个快时间谐波产生一个距离向复制峰；
- 每个慢时间谐波产生一个方位向复制峰；
- 两组谐波两两组合，最终形成二维复制点阵。

公式给出的是相邻谐波的基本间距，不代表每个谐波都具有相同亮度。亮度由具体的 0/π 码型及占空比决定。

## 4. 与原程序的直接关系

`SHIP.m` 中快时间码由下面两项共同决定：

```matlab
base_f = pss_configs{g, 2};
n_rep  = pss_configs{g, 3};
```

`base_f` 决定一个周期内部的相位形状，`n_rep` 决定一个脉冲中重复多少次。慢时间码通过循环索引：

```matlab
m_slow = curr_s_temp(mod(k-1, L_s) + 1);
```

反复施加，所以 `L_s` 就是慢时间周期长度。本教学代码把这两个“控制旋钮”改名为 `fast_cycles` 和 `slow_period_samples`，让它们与物理间距的关系更直观。
