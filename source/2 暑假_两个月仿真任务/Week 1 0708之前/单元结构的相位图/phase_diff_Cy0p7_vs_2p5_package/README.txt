Cy_val = 0.7 与 2.5 相位差绘图包
=====================================

本包从你提供的 CST XY Data Exchange 文件中，仅保留：
- Cx_val = 0.7, Cy_val = 0.7
- Cx_val = 0.7, Cy_val = 2.5

使用方法
--------
1. 解压整个文件夹。
2. 在 MATLAB 中进入该文件夹。
3. 运行：
   plot_phase_diff_Cy0p7_vs_2p5

脚本会生成：
- Cy=0.7 的展开相位曲线
- Cy=2.5 的展开相位曲线
- |Phase diff| 相位差曲线
- 180°±20° 灰色容差区域
- 满足容差的连续频带标注
- 鼠标点击数据点读取准确频率和相位差

文件说明
--------
plot_phase_diff_Cy0p7_vs_2p5.m
    可直接运行的 MATLAB 绘图脚本。

phase_diff_Cy0p7_vs_2p5.csv
    已按 Cy=0.7 的频率网格对齐，可直接绘图的数据。

raw_CST_Cx0p7_Cy0p7_Cy2p5.csv
    两条 CST 原始复数曲线及计算得到的相位数据。

raw_CST_Cx0p7_only_Cy0p7_Cy2p5.txt
    从原始 CST 导出文本中截取的两条目标曲线。

phase_diff_Cy0p7_vs_2p5_preview.png
    结果预览。

数据摘要
--------
最接近 180° 的频率：5.664000 GHz
绝对相位差：179.532057°
带符号相位差：-179.532057°
偏离 180°：0.467943°

按 160°～200° 的严格标准，连续有效频带为：
- 5.117700～5.314050 GHz，带宽 0.196350 GHz
- 5.508750～5.757750 GHz，带宽 0.249000 GHz

说明
----
原始 Cy=0.7 数据在局部采用了更密的频率采样；脚本已将 Cy=2.5
相位线性插值到 Cy=0.7 的频率网格。未进行频率范围外推。
