歼-36 4×4机群二维 SAR 电磁欺骗（第一版）

目标布局
- 4×4中心坐标为 [-12,-4,+4,+12] m，相邻间距 8 m。
- 四个角点放置真实歼-36。
- 每个角点向阵列内部进行距离向和方位向二维 1-bit 调制。
- 8个边缘点对应 (1,0) 或 (0,1) 一阶谐波。
- 4个内侧点对应 (1,1) 混合阶，不应称为普通的二次谐波。

编码方式
- 距离向和方位向分别使用 0/pi 两状态编码。
- 每个维度均为 0状态30%、1状态70%，以保留非零直流项。
- 两个编码相乘后仍然只有 +1/-1 两种瞬时反射状态。
- 纯1-bit实数编码必然产生正负阶镜像，并且30/70非平衡编码还会产生偶次谐波。
  因此结果图除了期望4×4位置，还会出现阵列外镜像和高阶杂散；代码不会人为删除。

运行方法
1. 散射点已经生成，可直接运行 SHIP_4x4.m。
2. 如需重新生成歼-36散射点，先运行 ship_trans.m，再运行 SHIP_4x4.m。
3. 只想查看各次谐波幅度时，运行 plot_harmonic_amplitudes.m，无需重跑SAR。
4. 平衡50%/50%编码实验运行 SHIP_4x4_balanced.m；结果保存到results_4x4_balanced。

平衡编码预期
- C0=0，所有偶数阶为0；因此四角零阶和边缘(1,0)/(0,1)目标消失。
- 主导的(±1,±1)阶在阵列中心形成2×2。
- 但±3、±5等奇数高阶仍存在，因此30 dB图不一定严格只剩4架；8 dB图突出中央2×2。

主要参数
- grid_spacing_m：4×4阵列中心间距，默认8 m。
- zero_state_fraction：每个一维编码中0相位状态比例，默认0.30。
- reflection_power_efficiency：超表面功率反射效率，默认0.80。
- resolution_mode：preview/uav/high，默认uav（约0.15 m分辨率）。

输出
- array_layout_4x4：理论4×4布局和阶次分类。
- sar_four_real_corners：只有四架真实飞机时的SAR图。
- sar_4x4_deception_1bit：二维1-bit编码后的SAR图，包括真实目标、期望假目标和杂散。
- sar_4x4_deception_1bit_full_field：扩大视场显示阵列外镜像和高阶杂散。
- one_bit_harmonic_amplitudes：距离向和方位向-5~+5阶理论谐波幅度图。
- one_bit_harmonic_amplitudes.csv：谐波复系数、线性幅度和归一化dB。
  图中以未加超表面的单架飞机幅度A=1为0 dB；不计80%反射效率。
- expected_positions_4x4.csv：16个期望格点及其来源角点。
- sar_results_4x4.mat：图像矩阵、坐标和编码参数。
