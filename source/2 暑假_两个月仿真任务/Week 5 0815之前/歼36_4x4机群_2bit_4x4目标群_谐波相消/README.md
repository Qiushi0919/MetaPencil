# 4架真实飞机生成4×4目标群，并抑制主要十字谐波

运行入口：`SHIP_4x4_to_4x4_partition_cancel_wide100.m`

## 一维编码结构

表面按面积分成两条空间支路：

- 未调制支路：产生零阶 `n=0`；
- 平衡2-bit分区调制支路：产生正一阶 `n=+1`，并利用四组循环时延抑制 `n=-3` 和 `n=+5`。

四组归一化循环时延为：

```matlab
[0, 1/10, 5/6, 14/15]
```

距离向和方位向分别保留 `{0,+1}`，所以二维共有：

```text
(0,0)  (0,+1)  (+1,0)  (+1,+1)
```

每架角点飞机产生上述四种位置组合。四架飞机共同形成坐标：

```text
距离：[-12, -4, +4, +12] m
方位：[-12, -4, +4, +12] m
```

即4×4共16个飞机像，其中四角是保留下来的零阶位置，其余12个是电磁假目标。

## 等幅面积比例

平衡2-bit正一阶幅度与分区因子乘积约为：

```text
|C+1 S+1| = 0.741536
```

为了使零阶和正一阶幅度相同，代码自动设置：

```text
未调制支路面积比例 = 0.425794
分区调制支路面积比例 = 0.574206
```

理想情况下，一维零阶和正一阶幅度均为 `0.425794`；二维四种组合幅度均为 `0.181301`，相对未调制单机约为 `-14.83 dB`。

这里的损失表示入射能量被分配给四个期望位置及剩余高阶谐波，不是额外手工设置的反射效率。
