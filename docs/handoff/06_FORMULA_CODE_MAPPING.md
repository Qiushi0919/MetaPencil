# 核心公式—代码映射

## 1. 雷达与 SAR 原始回波

对散射点 `i` 和慢时间 `t_m`，代码采用：

\[
R_i(t_m)=\sqrt{(v t_m-x_i)^2+y_i^2+H_0^2}
\]

\[
s_i(t_m,t)=a_i\,\mathrm{rect}\!\left(\frac{t-2R_i/c}{T_p}\right)
\exp\{j\pi K_r(t-2R_i/c)^2\}
\exp\{-j4\pi R_i/\lambda\}.
\]

| 理论量 | 代码变量 | 文件/位置 | 单位/默认值 | 硬编码/备注 |
|---|---|---|---|---|
| 光速 `c` | `c` | 主入口 28 行 | `3e8 m/s` | 硬编码 |
| 载频 `f_c` | `fc` | 29 行 | `10 GHz` | 硬编码 |
| 波长 `lambda` | `lambda=c/fc` | 30 行 | `0.03 m` | 计算 |
| 脉宽 `T_p` | `Tp` | 31 行 | `1 us` | 硬编码 |
| 入射角 `beta` | `beta` | 32 行 | `60°`，弧度存储 | 图中称入射角；侧视几何 |
| 高度 | `H0` | 33 行 | `500 m` | 硬编码 |
| 平台速度 | `v_x` | 34 行 | `80 m/s` | 硬编码 |
| 中心地距/斜距 | `Y0`,`R0` | 35–36 行 | `866.025/1000 m` | 计算 |
| 地距分辨率 | `desired_ground_range_resolution` | 40 行 | `0.25 m` | 当前主入口 |
| 方位分辨率 | `desired_az_resolution` | 41 行 | `0.25 m` | 当前主入口 |
| 带宽 | `Br` | 46–49 行 | `692.82 MHz` | 由地距分辨率与60°计算 |
| 调频率 | `Kr=Br/Tp` | 49 行 | `6.9282e14 Hz/s` | 正号 LFM |
| 采样率 | `Fs` | 50 行 | `831.38 MHz` | `1.2 Br` |
| 方位调频率 | `Ka` | 54 行 | `-426.667 Hz/s` | 代码采用负值 |
| PRF | `PRF` | 56 行 | `384 Hz` | 向上取整 |
| 快/慢样本数 | `Nr`,`Na` | 57–65 行 | `2048/288` | 当前默认 |
| 快时间 | `t`/`fast_time_relative` | 65、67 行 | 秒 | 围绕 `2R0/c` |
| 慢时间 | `tm` | 59 行 | 秒 | 对称孔径 |

散射点基础幅度没有随机表面起伏；只使用 `scatter_amplitude=(R0/r_inst)^2`。飞机高度、法向、极化和材料 RCS 不在当前主模型内。

## 2. 2-bit 四相位与傅里叶系数

平衡四态：

\[
q(\phi)\in\{e^{j0},e^{j\pi/2},e^{j\pi},e^{j3\pi/2}\},
\qquad \Delta\phi=\pi/2.
\]

代码 `fourPhaseRamp`（主入口 466–474 行）使用 `exp(+j state_phase)`；理论系数 `twoBitCoefficient`（595–607 行）采用：

\[
C_n=\frac{1}{2\pi}\int_0^{2\pi}q(\phi)e^{-jn\phi}\,d\phi.
\]

因此本项目的正负阶符号与 `e^{-jn\phi}` 定义绑定。理想平衡码：

\[
|C_{+1}|=\frac{2\sqrt2}{\pi}=0.900316,
\]

非零主序列为 `n=..., -7,-3,+1,+5,+9,...`。若外部文献采用 `e^{+jn\phi}`，阶次会镜像，比较前必须统一约定。

## 3. 调制频率到 SAR 偏移

代码对目标偏移 `Delta r_g`（地距）与 `Delta a`（方位）使用：

\[
f_r=-\frac{2K_r\,\Delta r_g\sin\beta}{c},
\qquad
f_a=-\frac{K_a\,\Delta a}{v}.
\]

对应主入口 `compilePhysicalResponse:431–436` 和 `shiftEcho:564–569`。偏移数组顺序始终为：

```text
offsets(:,1) = 距离/地距，绘图 x 轴
offsets(:,2) = 方位，绘图 y 轴
```

当前 0.25 m 分辨率下，±8 m 得 `|f_r|=32 MHz`、`|f_a|=42.6667 Hz`。Week4 0.15 m 地距分辨率下，同样 8 m 得 `|f_r|=53.333 MHz`；所以 53.33 MHz 不是固定“载波”，而是由 `Kr` 和目标偏移共同决定的调制基频。

每个维度的调制周期是：

\[
T_r=1/|f_r|,\qquad T_a=1/|f_a|.
\]

平衡 2-bit 每周期有四个状态槽，理想最小状态刷新率约为 `4|f|`。8 m 当前默认对应距离刷新约 128 MHz；高精度 0.15 m 版本约 213.33 MHz。方位状态刷新约 170.67 Hz。

## 4. 四时延 H primitive

代码的归一化循环时延：

\[
d=[0,\,1/10,\,5/6,\,14/15].
\]

对第 `n` 阶的分区因子：

\[
S_n=\frac14\sum_{p=1}^{4}e^{-j2\pi n d_p}.
\]

代码位置：主入口 371–375、439–446 行；公共 2-bit 核心 421–429 行。数值：

| 阶次 | `|S_n|` | 作用 |
|---:|---:|---|
| `+1` | `0.823639103546` | 保留但有分区损失 |
| `-3` | `~1.96e-16` | 理想数值零陷 |
| `+5` | `~9.21e-16` | 理想数值零陷 |
| `+9` | 接近零 | 顺带抑制 |

单维目标主阶：

\[
|C_1S_1|=0.7415357.
\]

二维 `(+1,+1)` 场幅：

\[
|A_{1,1}|=|C_1S_1|^2=0.5498752\quad(-5.195\ \mathrm{dB}).
\]

这里 dB 是**场幅的 20log10**，相应功率比例为 `0.549875^2≈30.24%`，不是 54.99%。

## 5. 二维 4×4 组合

理论 H primitive 有 16 个 `P_pq`：距离行选择 `d_p`，方位列选择 `d_q`。在理想可分离条件下：

\[
C_{mn}^{(2D)}=(C_mS_m)(C_nS_n).
\]

代码没有创建 16 个大 `Na×Nr` 矩阵，而是先分别算四项平均，再用：

```matlab
azimuth_average .* range_average
```

得到同一外积。这在以下条件下严格：二维调制函数能写成 `q_r(t_fast)q_a(t_slow)`、子单元等幅、两个方向延迟独立、线性远场相干叠加。真实口径互耦、状态幅度不同、入射角随孔径变化或共享控制时序耦合时，只是仿真假设。

时延单位是**各自维度周期的归一化比例**，不是一套固定纳秒同时用于快/慢时间：距离子延迟为 `d_p T_r`，方位子延迟为 `d_q T_a`。物理实现必须提供等效的两个相位偏置/调度自由度。

## 6. H_k 外层码本与多目标幅度

第 k 个通道由：

```text
H_k = (range_offset_k, azimuth_offset_k, tile_count_k, area_fraction_k)
```

表示。`balancedTileMap(N,K)` 把 `N^2` 个宏格硬分给 K 个通道：

\[
w_k=N_k/N^2.
\]

总响应：

\[
Q(t_m,t)=\sum_k w_k Q_k(t_m,t).
\]

单机 `1→K` 的理想主阶场幅约为：

\[
A_k\approx w_k(C_1S_1)^2.
\]

例如 4×4 外层的 `1→2` 有 8/8 格，每个目标约 `0.2749376` 场幅（相对未调制单机约 -11.22 dB）；`1→4` 每个 4/16 格，约 `0.1374688`（约 -17.24 dB）。实际 SAR 峰值会受飞机散射结构、旁瓣、相位和目标重叠影响。

## 7. 真实和假目标位置

- 单机：`target_position = offsets`，真实飞机位于 `[0,0]`，主入口通常不保留未调制零阶。
- 多机：`target_position = source_position + offsets`。
- 四机主入口真实位置：`[-12,-12]`, `[12,-12]`, `[-12,12]`, `[12,12]` m。
- Week5 DC/+1 特殊 4→16 版本把未调制支路与 `+1` 支路同时保留；与主入口纯通道分配策略不同，不能混为一套幅度公式。

## 8. 多机坐标与相位

`shiftEcho` 不是重新逐点生成每架飞机，而是：

\[
s_{shift}=s_{center}\exp\{j2\pi(f_a t_m+f_r(t-2R_0/c))\}.
\]

然后各机 `sr_source.*response` 在 `sr_case` 中复数求和。它保留线性平移相位，但忽略真实大偏移下的高阶几何差、姿态和不同散射可见性。

## 9. RD 成像输出

`rdFocus`：

1. `H_range=conj(FFT(h_ref))`，距离匹配滤波；
2. 方位 FFT；
3. `interp1` 实现 RCMC；
4. `H_az=exp(+j*pi*fa^2/Ka)`；
5. 方位 IFFT。

输出 `img` 是复数 SAR 图像 `I(r,a)`。主绘图：

\[
I_{dB}=20\log_{10}|I|-20\log_{10}(I_{single,peak}).
\]

`set(gca,'YDir','normal')` 使方位正方向向上；手机 mask 也明确把图像上方映射为正方位。历史脚本可能用不同裁剪/动态范围，比较前看 `07_RESULTS_TRACEABILITY.md`。
