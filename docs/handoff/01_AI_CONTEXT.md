# 给下一位 AI / 研究者的 MetaPencil 上下文

## 1. 研究目标与论文切口

MetaPencil 研究“时变数字编码超表面如何把真实散射目标的 SAR 像重构为可编程假目标群”。当前最有辨识度的科学问题不是单纯生成假目标，而是：在单极化 2-bit 四相位硬件约束下，怎样保留指定 `(+1,+1)` 谐波通道，同时抑制均匀四相位阶梯必然产生的 `(-3,+1)`、`(+5,+1)`、`(+1,-3)`、`(+1,+5)` 外侧十字副像，并进一步把外层口径自由度用于多目标与多机独立码本。

长期目标是在约 2 m×2 m 的无人机模型上铺设分区共形可编程超表面。**共形全波模型、FPGA 控制和实物实验尚未实现。**

## 2. 核心技术链

```text
30/70 1-bit 基线
  -> 零阶、正负谐波和二维混合阶
平衡 2-bit 四相位基线
  -> +1 主阶集中，但保留 ..., -7,-3,+1,+5,+9,...
4×4 二维延迟基元 H
  -> 行/列分别平均 4 个循环时延，给 -3/+5 阶形成复相量零陷
外层 H_k 目标通道分配
  -> 每个宏格选择一个距离/方位偏移通道与面积权重
单机 1->N
  -> 一个真实回波通过 K 个空间面积通道生成 K 个位置
多机协同/独立编码
  -> 每架飞机的复原始回波先平移到真实位置，再乘各自响应并复数求和
自定义 RD 成像
  -> 距离压缩、方位 FFT、RCMC、方位匹配滤波、IFFT
```

## 3. 当前主实现

### `run_full_array_freedom_study.m` — Confirmed

- 路径：`source/2 暑假_两个月仿真任务/Week 5 0815之前/SAR假目标自由度与物理阵列/`
- 作用：当前统一入口；单机、双机、四机、4/5/7 外层阵列和任意 7×7 形状。
- 关键证据：原文件 1–11 行声明完整链路；74–109 行生成中心歼-36 LFM 原始回波；141–178 行 `1→N`；201–246 行双机复回波；248–272 行四机；422–464 行把整数宏格编译为二维 2-bit 响应；572–593 行自定义 RD。
- 关键参数：10 GHz、60°、500 m、80 m/s、0.25 m 地距/方位分辨率、700 点、8 m 网格、-36 dB、四态 `[0,90,180,270]°`、时延 `[0,1/10,5/6,14/15]T`。
- 输出：`results_full_array_exact/`；交接包映射到 `outputs/latest/`、`single_uav/`、`multi_uav/`。
- 验证：代码、现有 PNG/CSV/MAT 与烟雾测试一致；本次未重跑全部 700 点批量。

### Week 4 `SHIP_4x4.m` — Confirmed baseline

- 30/70 1-bit，四角 4 架真实歼-36，各自使用独立距离/方位方波向内搬移 8 m。
- 原文件 194–235 行在复原始回波上乘二维 1-bit 码；不是图像复制。
- 未加额外“反射效率”：`reflection_power_efficiency=1`。

### Week 4 `SHIP_4x4_ssb_2bit.m` — Confirmed reusable core

- 默认平衡 2-bit；接受驻留比例、时延集合、显示范围、DC 支路面积等外部变量。
- 339–398 行生成二维四态响应；421–429 行显式计算复数分区因子。
- 4×4 基元模式只允许理想等幅四态；遇到非理想状态会报错并要求显式累加 16 联合状态。

### `run_target_freedom_study.m` — Partial / legacy

- 它加载完整 RD 得到的**单机复图像**，随后提取 `abs(img)` 模板并在图像幅度域插值、平移、加权相加（原文件 349–376 行）。
- 因此适合快速构思和面积/目标数量预算，但“相干增强”只是幅度权重累计，不是严格的复电场相干叠加。
- 不可用它单独证明多机电磁相干、路径相位或旁瓣行为。

## 4. 数学对象与代码变量

| 理论对象 | 主要代码变量 | 含义 |
|---|---|---|
| 2-bit 四态 | `state_response` | `exp(+j[0,90,180,270]°)`，默认等幅 |
| 状态驻留 | `state_dwell_fraction` | 平衡码 `[0.25,0.25,0.25,0.25]` |
| H primitive | `inner_delay_fraction` + 两个独立四项平均 | 每个 H_k 内部重复的 4×4 行列时延笛卡尔积 |
| `P_pq` | 没有显式 16× 大矩阵；由 `range_average.*azimuth_average` 等效 | `p` 选距离时延，`q` 选方位时延 |
| `R_i` | `inner_delay_fraction(i)` 在 `range_average` 中 | 距离维循环时延组 |
| `A_j` | 同一集合在 `azimuth_average` 中 | 方位维循环时延组 |
| H_k | `offsets(channel,:)` 和 `channel_id` | 第 k 个目标通道；不是新的四相位硬件状态 |
| 外层阵列 | `tile_map` | 每个宏格分配给哪个 H_k |
| 面积权重 | `counts/numel(tile_map)` | 硬分组的面积占比 |
| 距离偏移 | `offsets(:,1)` | 米；图像横轴 |
| 方位偏移 | `offsets(:,2)` | 米；图像纵轴 |
| 二维响应 | `azimuth_average.*range_average` | 明确采用可分离乘积近似 |

不要把“外层 4×4 H_k 阵列”和“每个 H_k 内部的 4×4 延迟基元”混为一谈；前者分配目标通道，后者抑制高阶。

## 5. 关键物理和数值假设

- 雷达：10 GHz 侧视单站 SAR，60° 入射，500 m 高，平台 80 m/s，LFM；参数是研究仿真假设，不是某一真实雷达标定。
- 飞机：纯 2D、3000 个等基础幅度散射点；主入口均匀抽取至 700 点。没有 PO/MoM/FDTD RCS、遮挡、多次散射或高度。
- 传播：每点使用 `(R0/r)^2` 场幅衰减与双程相位；没有天线方向图、噪声、大气、极化矩阵。
- 超表面：理想单极化、无损、四态等幅、恰好 90°；忽略互耦、斜入射幅相漂移、带宽色散和开关过渡。
- 二维可分离：代码假定距离快时间与方位慢时间响应可分离，并把两个一维平均相乘。这在理想乘积调制与独立控制下成立；对真实共享硬件时钟、耦合和时变入射角不是自动严格成立。
- 多机：主入口在**复原始数据层**求和，保留代码内的相位；但没有独立时钟误差、平台同步误差、机体姿态或真实相对路径重新积分，仅以中心模板的相位乘子平移。
- 外层多目标：采用孔径/面积硬分组，`tile_map` 决定权重；不是全口径连续相位联合优化。
- 归一化：主入口统一除以未调制中心单机峰值；部分旧绘图脚本逐图归一化，不能混比。

## 6. 真正已解决与尚未解决

已解决（仿真层面）：

- 1-bit 与平衡 2-bit 高阶谱；
- `-3/+5` 复相量零陷；
- 二维系数外积与主要十字副像抑制；
- 单机/多机多目标的整数通道编译；
- 自定义 LFM+RD 成像与统一单机峰值参考；
- 控制表 CSV 导出。

未解决：

- 宽带斜入射下四态等幅/90°的真实单元与共形整机；
- 距离快时间几十 MHz（四态刷新约 4 倍）和方位慢时间几十 Hz 的联合硬件调度；
- 2 m×2 m 口径的互耦、馈电网络、偏置线、同步和 FPGA；
- 相位误差、时延抖动、幅度不平衡下零陷深度统计；
- 严格能量守恒、目标区积分功率、PSLR/ISLR/分辨率指标；
- 物理多机相干/非相干边界；
- 全波或实测验证。
