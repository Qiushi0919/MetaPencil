# MetaPencil 模型层级与可声明结论

## L0：理论谐波系数

离散时序的傅里叶系数和循环时延相量。可验证谐波幅相与理想零陷，不能验证 SAR 聚焦或实体口径。

## L1：理想可分离二维调制

距离快时间响应与方位慢时间响应相乘。可研究二维阶次组合；共享硬件时钟和真实耦合仍需验证。

## L2：二维点散射体复原始回波 + RD

当前主要实现。可比较理想调制前后的 SAR 目标位置与强度，但不含全波 RCS、互耦、遮挡、极化矩阵、杂波和噪声。

## L3：位置感知有限口径分区

尚未实现。需要为每个宏格建立物理坐标、局部状态时序和散射点/三角面所有权，并计算局部传播和口径相位。只有达到此层级，才能讨论不同 `tile_map` 排布造成的空间栅瓣和局部散射差异。

## L4：全波、共形和硬件

尚未实现。包括宽带斜入射四态单元、互耦、共形曲率、偏置网络、FPGA 刷新、同步、状态过渡、实测 RCS 和真实 SAR。

所有图、表和论文陈述都应标注实际达到的最高层级。
