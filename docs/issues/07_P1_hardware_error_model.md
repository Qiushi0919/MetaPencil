# P1 — Add 2-bit hardware amplitude, phase and timing errors

Labels: `P1`, `hardware`, `physics`

## Goal

Replace ideal equal-amplitude 90° states with frequency/angle/polarization-dependent complex states and controller timing errors.

## Acceptance

- Supports per-state amplitude/phase, delay jitter, duty error and transition time.
- Monte Carlo scan reports target efficiency and `-3/+5` residual distributions.
- Ideal mode reproduces the current smoke coefficients.
- Input evidence is labeled full-wave or measured with operating conditions.
