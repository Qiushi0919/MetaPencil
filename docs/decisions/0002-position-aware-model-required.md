# ADR-0002：空间排布结论必须使用位置感知模型

- 状态：Accepted
- 日期：2026-08-24

## 现状

`compilePhysicalResponse` 只从 `tile_map` 取得各通道数量和面积权重；各 H_k 作用于完整飞机复回波。

## 决策

在实现宏格物理坐标、散射点/三角面分配及局部传播相位之前：

- 不宣称当前蛇形或均匀交织排布已抑制实体口径栅瓣；
- 不用不同 `tile_map` 图案但相同计数的结果证明空间优化；
- 把当前结果描述为理想面积混合/细密交织近似。

## 下一步验收

同样通道计数、不同空间排布应在新模型中可能产生不同口径响应；把新模型与当前面积混合极限做收敛比较。
