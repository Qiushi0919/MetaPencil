# 超表面 MATLAB 报告复现

当前入口在 `Matlab-code/code/`，默认采用轻量保存。在 MATLAB 中打开 **`code/main_study.m`**，点击“运行”，即可从散射点重新生成回波、完成 RD 聚焦并输出报告中的 SAR 对比。程序不依赖 `项目管理/review_packets/`，也不使用旧结果缓存。

MATLAB R2025a 为本次验证环境。默认仍完整计算700个散射点、2426条回波，每条32768个复数样本；当前只保存PNG图片、参数、指标和运行记录，本次实测输出7.43 MB。采样和计算精度保持，运行内存仍较大。本次在24 GB内存机器上，数值计算约7.5分钟、含绘图约8分钟；耗时随机器变化。输出放在 `code/results_report/日期_时间/`，每次运行新建目录，不覆盖历史结果。

## 函数调用

```matlab
% 默认完整报告案例
result = main_study_spatial;

% 只计算单点，仍用完整孔径和采样
point = main_study_spatial(struct('mode','point','make_plots',false));

% 独立采样加密对照
fine = main_study_spatial(struct('mode','point','Fs',19.2e9,'PRF',3072));
```

轻量结果不含可后处理的复数矩阵或可编辑FIG。若以后需要改成像处理、查看新的复数剖面或重新绘图，必须重新计算；已有PNG可以直接用于汇报。`plot_report_results`的单参数调用仅兼容以前保存的完整MAT目录。可用`output_dir`指定新的或空的输出目录。改变Fs或PRF后会重算采样点数，不再是默认报告配置。新版默认范围为报告1→4案例；旧`case_ids`、`tile_map`接口保留在备份程序中。

## 计算流程保留内容

`makeCells`保留每个单元的坐标、所属通道和快慢延迟类型；`fourPhaseRamp`生成理想四态复系数。`positionResponse`把单元的快、慢复系数相乘，再结合其坐标对应的双程传播相位做相干求和；相同码历史按组计算，`directPositionResponse`逐单元求和校验保留。`echoPoints`的复回波生成及`rdFocus`的距离压缩、距离徙动校正、方位压缩均不变。

运行中仍使用双精度复数；轻量修改只去掉落盘存档。缺少的是以后无需重算就能读取完整原始回波、阵列复响应、复图像、时序快照或编辑FIG的能力。当前单元系数仍为理想0/90/180/270°，不等同于全波或实测单元S参数。

## 模型边界

这是理想载频有限阵因子乘完整目标复回波，再用报告相同的RD算法聚焦。水平空间模型包含单元坐标和移动雷达的阵内双程相位，但没有实现散射点对物理分区的归属，也未接入实际宽带斜入射四态单元、互耦、噪声或实测数据。

显示−80 dB弱结构不表示实际可检测，既有检查没有证明全部−80 dB旁瓣收敛。0.25 m是方位设计输入，Fs和PRF是数值设置。9–10 GHz为发射频段，调制主阶可能越出该频段，真实器件和接收频带仍需另行验证。
